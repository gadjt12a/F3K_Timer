F3K Timer fw-v30
Date: 2026-08-01
Source commit: cf602ea

Flash addresses (esptool):
  0x00000  bootloader.bin
  0x08000  partitions.bin
  0x10000  firmware.bin

esptool command:
  esptool.py --chip esp32s3 --port COM4 --baud 921600 write_flash 0x0 bootloader.bin 0x8000 partitions.bin 0x10000 firmware.bin

Wire-flashing from the base station Pi instead: see SESSION_STATE.md
"Flashing the timer from the Pi". Needs --no-stub, and if the device has taken
an OTA since its last wired flash, otadata at 0xe000 must be cleared or the
bootloader keeps launching the other slot and the flash appears to do nothing.

REQUIRES a base station with the SCRATCH handler (I-42). This is a hard pairing,
not a nice-to-have:

An older base logs "Unknown command" and sends no ACK, so the timer retries the
SCRATCH forever and the entry never leaves the pending queue. The queue holds 32
entries and drops the NEWEST when full -- so enough stuck scratches would start
discarding live FLIGHTs. Do not run fw-v30 against a base station older than
I-42.

The base station deployed alongside this release has the handler.
